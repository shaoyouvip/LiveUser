LiveUser 服务介绍
LiveUser 使用 Go + WebSocket 统计当前在线连接数，并使用 Cloudflare Worker + D1 统计当天页面访问量（PV）。每次页面加载或刷新都会累计一次。
  • 实时在线： Go WebSocket 长连接按站点推送当前连接数
  • 访问量统计： Cloudflare Worker + D1 每次页面访问累计 PV
  • 隐私优先： 不读取 IP、User-Agent、Referer，不保存访客身份
  • 多站点支持： 默认按当前页面域名隔离统计
  • 可独立部署： WebSocket 容器与 Cloudflare Worker 可分别部署

原始项目（作者 Mingyu / ymyuuu）：https://github.com/ymyuuu/LiveUser

						常见问题
						

							
    
								
  • Q: 能否统计多个站点？
									
    不需要额外配置。每个网站默认按自己的页面域名统计；需要合并多个域名时，再为它们设置相同的 siteId。
    
								
    • 
								
  • Q: 支持哪些浏览器？
									
    支持所有现代浏览器，包括移动端浏览器。
    
								
    • 
								
  • Q: 如何自定义动画效果？
									
    通过 CSS 自定义 .updating 类的样式。
